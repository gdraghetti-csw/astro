Le regole di spacing per la parte web si basano sulla regola deli 8x alla quale introducono valori intermedi di 4px per le dimensioni inferiori a 16 pixel.
Questo avviene per rispondere alle necessità di spazi più ridotti, mantenendo comunque una coerenza visiva.

Nella pratica, questa eccezione viene applicata come segue:

0px: Nessuno spazio
4px: Utilizzato per microspaziature, come la distanza tra icone molto piccole o il padding interno di bottoni di piccole dimensioni.
8px: Spaziatura minima standard.
12px: Un'opzione intermedia tra i multipli di 8, per situazioni che richiedono una finezza maggiore.
