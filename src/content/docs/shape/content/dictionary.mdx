## Acronimi informatica

una lista dei principali acronimi utilizzati nel software aziendale

|           |                                                                                                                                                                                                                                                                    |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **ADK**   | Application Designer Kit. Framework di strumenti dedicati allo sviluppo e al design rapido di regole, layout e programmi applicativi.                                                                                                                              |
| **BI**    | Business Intelligence. Analizza i dati aziendali per fornire informazioni utili a prendere decisioni strategiche.                                                                                                                                                  |
| **BPM**   | Business Process Modeler. Modella e ottimizza i processi aziendali.                                                                                                                                                                                                |
| **CMMS**  | Computerized Maintenance Management System. Consente di gestire la manutenzione degli impianti e delle attrezzature aziendali.                                                                                                                                     |
| **CMS**   | Content Management System. Permette di creare e gestire siti web e contenuti digitali.                                                                                                                                                                             |
| **CRM**   | Customer Relationship Management. Si concentra sulla gestione delle relazioni con i clienti, acquisizione, fidelizzazione e supporto.                                                                                                                              |
| **CRP**   | Capacity Resource Planning. Permette di verificare costantemente la capacità produttiva necessaria e disponibile per fare fronte alle richieste dei clienti nel rispetto dei tempi concordati e del mantenimento del livello ottimale delle giacenze di magazzino. |
| **DRP-I** | Distribution Requirements Plannings. Strumento di controllo che permette di individuare all’interno di una finestra temporale quando le diverse tipologie dei magazzini (ad es. le ubicazioni di picking, stocking, overstock…) andranno in sofferenza.            |
| **ERP**   | Enterprise Resource Planning. Un software gestionale completo che integra diverse aree aziendali, come contabilità, produzione, magazzino, vendite e risorse umane.                                                                                                |
| **FCS**   | Finite Capacity Scheduling. Schedulazione a capacità finita.                                                                                                                                                                                                       |
| **HRM**   | Human Resource Management. Automatizza i processi legati alle risorse umane, come assunzioni, formazione, gestione del personale e payroll.                                                                                                                        |
| **MES**   | Manufacturing Execution System. Gestisce e controlla la produzione in tempo reale.                                                                                                                                                                                 |
| **MPS**   | Master Production Scheduling. Piano Principale di Produzione, rappresenta le modalità con cui l'azienda risponde alla domanda di mercato (forecast e ordini cliente) nel medio-lungo periodo.                                                                      |
| **MRP**   | Material Requirements Planning. Pianifica le necessità di approvvigionamento dei materiali.                                                                                                                                                                        |
| **OEE**   | Overall Equipment Effectivess. Fornisce elementi fondamenti per valutare le successive azioni da intraprendere per ottimizzare costi e risorse.                                                                                                                    |
| **PDM**   | Product Data Management. Gestisce in modo centralizzato tutti i dati tecnici di prodotto grazie all’archiviazione, classificazione, tracciabilità e sicurezza dei documenti tipici dell’ufficio tecnico.                                                           |
| **PLM**   | Product Lifecycle Management. Gestisce il ciclo di vita del prodotto, dalla progettazione alla dismissione.                                                                                                                                                        |
| **QMS**   | Quality Management System. Gestisce la qualità dei prodotti e dei processi aziendali.                                                                                                                                                                              |
| **RGT**   | Report Generation Tool. È lo strumento che, utilizzando un ambiente grafico, permette di modificare in modo semplice e autonomo le stampe esistenti o di creare nuovi layout di report e documenti.                                                                |
| **SCADA** | Supervisory Control and Data Acquisition. Monitora e controlla i sistemi industriali in tempo reale.                                                                                                                                                               |
| **SCM**   | Supply Chain Management. Gestisce la catena di approvvigionamento, dall'acquisto delle materie prime alla consegna del prodotto finito.                                                                                                                            |
| **SDK**   | Software Developmet Kit. Per sviluppare programmi e applicazioni verticali che si integrano con le strutture dei Data Base esistenti, sfruttandone la “business logic” e mantenendo la coerenza e l’integrità dei dati.                                            |
| **SFA**   | Sales Force Automation. Automatizza i processi di vendita, lead generation e gestione del ciclo di vendita.                                                                                                                                                        |
| **WMS**   | Warehouse Management System. Riconoscimento e movimentazione delle merci mediante lettura dei bar-code utilizzando terminali wireless collegati in tempo reale con il sistema centrale.                                                                            |

## Acronimi relativi all’azienda e ai job role

|          |                                                                                                                                                                                                                                                              |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **AD**   | Amministratore Delegato. L’AD è a tutti gli effetti un membro di un CDA, tuttavia, è un membro con delle peculiarità che lo pongono al di sopra degli altri nella gerarchia aziendale.                                                                       |
| **CDA**  | Consiglio di Amministrazione, ossia l’organo collegiale che presiede alle decisioni e alla gestione di una società di capitali (per esempio SPA, SAPA, SRL). In inglese l’acronimo CDA è reso con BofD, BOD o BD, acronimi che stanno per Board Of Director. |
| **CEO**  | Chief Executive Officer (Amministratore Delegato, AD).                                                                                                                                                                                                       |
| **CFO**  | Chief Financial Officer (Direttore finanziario).                                                                                                                                                                                                             |
| **CInO** | Chief Innovation Officer. Si occupa più in generale di coordinare i processi di innovazione dell’azienda e potenziarne le capacità di fare innovazione.                                                                                                      |
| **CIO**  | Chief Information Officer (IT Manager, responsabile delle tecnologie inerenti l’informazione e le comunicazioni aziendali).                                                                                                                                  |
| **CISO** | Chief Information Security Officer (Responsabile della gestione della sicurezza delle informazioni e della protezione dei dati).                                                                                                                             |
| **COO**  | Chief Operations Officer (Direttore operativo).                                                                                                                                                                                                              |
| **HQ**   | Headquarters, quartier generale, la sede centrale di un’azienda, di una società o di un gruppo industriale.                                                                                                                                                  |

## Acronimi relativi agli scambi in ufficio, contesto aziendale

|          |                                                                                    |
| -------- | ---------------------------------------------------------------------------------- |
| **ASAP** | As soon as possible (il prima possibile).                                          |
| **FYI**  | For your information (per tua informazione).                                       |

## Acronimi generici

|          |                                                                                                                                                                                     |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **FAQ**  | Frequently Asked Questions. Spazio web in cui sono elencate le domande e le risposte più comuni, le cosiddette «Domande frequenti».                                                 |
| **KPI**  | Key Performance Indicator, ossia una serie di indicatori per la misurazione dell’efficienza e/o della performance di un’azienda o di una sua parte.                                 |
| **ROI**  | Return on Investment. Traducibile come “ritorno sul capitale investito”, permette di misurare l’efficienza di un investimento.                                                      |
| **SEM**  | Search Engine Marketing. Questa sigla fa riferimento alle attività di marketing legate ai motori di ricerca.                                                                        |
| **SEO**  | Search Engine Optimization. Questa espressione viene utilizzata dai professionisti del marketing per indicare le attività di marketing digitale che riguardano i motori di ricerca. |
| **SWOT** | Strengths, Weaknesses, Opportunities and Threats, che in italiano sta per: punti di forza, punti di debolezza, opportunità e minacce.                                               |
| **UI**   | User Interface (Interfaccia utente).                                                                                                                                                |
